# Summary

## 60-second brief

MD&A Q2/2569 ของ STPI (ลงนาม 14 ส.ค. 2569, เผยแพร่ SET 17 ส.ค.) อธิบายว่ารายได้ดำเนินงานรวม **959 ล้านบาท** (+4% YoY) โดยรับจ้างผลิตโตแรงหลังส่งมอบงานโมดูล ขณะที่ขายและบริการหดเพราะงานรื้อถอนแท่นขุดเจาะจบแล้ว. ส่วนงาน **ไฟฟ้า** รายได้ **112 ล้านบาท** (+16%) ต้นทุน **73** — ใกล้เคียงปีก่อนตามข้อความฝ่ายจัดการ. บริษัทพลิกเป็น**ขาดทุนสุทธิส่วนผู้ถือหุ้น 22 ล้านบาท** จากกำไร 83 ปีก่อน เพราะขาดทุนยกเลิกสัญญาเช่าครั้งเดียว 59.4 ล้านบาท, ส่วนแบ่งขาดทุนลม Monsoon 65 ล้านบาท (ช่วงลมน้อย), และภาษีที่เพิ่ม. F45 สอดคล้อง: Q2 (22,479) พันบาท / 6M กำไร 2,046 พันบาท. **ไม่มีตัวเลข MW โซลาร์ในเอกสารนี้**.

## Thesis of the source

ฝ่ายจัดการเล่าว่าผลดำเนินงานกลุ่มถูกกดด้วยรายการที่ไม่ใช่ core รับจ้างผลิต (lease termination + JV ลมตามฤดูกาล + ภาษี) แม้รายได้รวมและงานรับจ้างผลิตจะยังโต และไฟฟ้ายังรับรู้ใกล้เคียงปีก่อน. Narrative นี้ชี้ไปที่ timing ของงานบริการและรายการครั้งเดียวมากกว่าการพังของส่วนงานไฟฟ้า.

## Key numbers to remember

- รายได้ดำเนินงาน Q2: **959 ล้านบาท** (+4%); รับจ้างผลิต **735** (+54%); ขายและบริการ **77** (−76%); ไฟฟ้า **112** (+16%); เช่า **35**
- ต้นทุนไฟฟ้า **73** ล้านบาท; GPM รวมประมาณ **31%** (ปีก่อน 35%); กำไรดำเนินงาน **117** (−26%)
- ขาดทุนยกเลิกสัญญาเช่า **59.4** ล้านบาท (เงินคืน 34); ส่วนแบ่งขาดทุน IMH/Monsoon **65**; ส่วนแบ่งกำไร SP **3**
- ขาดทุนสุทธิส่วนผู้ถือหุ้น Q2: **22 ล้านบาท** (ปีก่อนกำไร 83) — ตรง F45 (22,479) พันบาท
- ค่าใช้จ่าย admin **80** (−19%) รวมค่าซ่อมโรงไฟฟ้าขยะชุมชนเตรียมเปิดเชิงพาณิชย์

## What changes my mind?

- ถ้า Q3 งานรื้อถอนแท่นขุดเจาะกลับมาตามที่บอก แต่ไฟฟ้าหด → narrative “ไฟฟ้าเสถียร” ใช้ไม่ได้
- ถ้าขาดทุน Monsoon ยังลึกทั้งในฤดูลมดี → ไม่ใช่แค่ seasonality
- ถ้าโรงไฟฟ้าขยะชุมชนเลื่อน COD ออกจาก Q4 → ค่าซ่อม/สินทรัพย์ระหว่างทำจะกดนานกว่าที่ MD&A สื่อ
